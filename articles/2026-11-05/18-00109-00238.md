# Walmartが放つAIコマース普及に3本の矢　Amazonと対照的な戦略を分析

AIエージェントが消費者の代わりに買い物をする「エージェンティックコマース」をめぐり、外部エージェントを締め出す方向のAmazonに対し、Walmartは2026年10月に外部エージェントを正式な利用主体として受け入れる方針を打ち出した。記事はその具体策として、利用者アカウント内にエージェント専用の枠を設けて予算上限や承認を管理する「Agent Profiles」、MCPを使いブラウザー操作を介さずに安定・高速に購買できる専用接続口「Walmart Agent Gateway」、エージェント向け利用規約の3つを解説する。顧客データや購買履歴はWalmart側に留め、AI企業に渡さない設計になっている点が要で、AI企業に顧客接点を中抜きされないための先手と位置づける。既存小売がAI企業と対峙しつつ共存する道筋として、日本企業が学ぶべき点を探る内容。
