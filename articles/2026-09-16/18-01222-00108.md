# 札幌市の「Sapporo Game Camp」、参加者の試遊作品など出展【TGS2026】

札幌市が参画する産官学連携のゲームイベント「Sapporo Game Camp」実行委員会が「東京ゲームショウ2026」に出展する。学生中心の参加者がプロクリエイターとチームを組んで制作した「Sapporo Game Camp 2025」の20作品全てを試遊出展するほか、運営協力企業7社のゲームや、道内教育機関4校の展示も行う。あわせて、札幌で開催されるeスポーツ大会「Apex Legends Global Series Championship」の紹介や、次回イベント「Sapporo Game Camp 2026」の参加者募集についても伝える。
